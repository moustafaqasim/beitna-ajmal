# بيتنا أجمل – Family Balance Tracker

## النشر على GitHub Pages
1. فك ضغط الملف.
2. أنشئ مستودع GitHub جديداً باسم `beitna-ajmal` واجعله Public.
3. ارفع **محتويات** هذا المجلد إلى جذر المستودع؛ يجب أن يكون `index.html` في الجذر مباشرة.
4. افتح Settings → Pages.
5. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)`، ثم Save.
6. بعد اكتمال النشر افتح الرابط الذي يعرضه GitHub Pages.
7. على Android باستخدام Chrome: قائمة ⋮ → Install app أو Add to Home screen.

## حفظ البيانات والخصوصية
- لا يوجد تسجيل دخول أو خادم قاعدة بيانات.
- التقييمات محفوظة في LocalStorage داخل المتصفح والجهاز الحالي فقط.
- لا تتم مزامنة البيانات تلقائياً بين الأجهزة.
- من تبويب «إدارة النقاط» صدّر نسخة JSON احتياطية بانتظام.
- لا تمسح بيانات الموقع/المتصفح قبل تصدير النسخة الاحتياطية.

## تحديث التطبيق
عند نشر إصدار جديد، غيّر قيمة `CACHE_NAME` في `service-worker.js` (مثلاً إلى `beitna-ajmal-v2`) ثم ارفع الملفات مجدداً.

## الملفات
- `index.html`: التطبيق الكامل.
- `manifest.json`: إعدادات تثبيت التطبيق.
- `service-worker.js`: التخزين المؤقت والعمل دون اتصال بعد أول زيارة ناجحة.
- `icons/`: أيقونات PNG وSVG.
